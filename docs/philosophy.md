# 交易系统顶层设计白皮书

> 版本: v0.1 | 2026-06-02
> 状态: 初稿
> 本质: 本文件不是操作手册，是设计约束——所有代码决策必须与这里的哲学一致。

---

## 0. 核心哲学声明

**本系统是倾向派交易系统。**

市场存在可识别的内部状态（吸筹/拉升/派发/下跌/震荡）。系统的首要任务不是预测价格，而是**正确识别当前状态，匹配相应的操作规则**。

反推：如果市场是纯随机的，本系统不成立。接受这个前提才能使用这套系统。

## 1. 概率三元组架构

系统同时使用三种概率范式，各自有明确定义的范围和责任。

### 1.1 倾向派 — 核心层

**责任：** 回答"市场现在处于什么状态"

| 组件 | 测量对象 | 输出 | 评估指标 |
|------|---------|------|---------|
| `_classify_wyckoff_phase()` | 大盘指数（量价结构） | Accum_A/B/C / Markup / Dist_A/B / Markdown / Range | 事后标注一致率 ≥ 80%（人工抽检 20 个交易日） |
| `PHASE_SIGNAL_MAP` | 个股威科夫信号 | 信号是否有效（该阶段下） | 各阶段信号命中率（见 3.1） |
| 2D 门控矩阵（行） | 大盘阶段 | 开仓/不开仓/轻仓的"阶段维度" | 正确拦截率（见 3.2） |

**注意：** 2D 门控矩阵的行（Wyckoff 阶段）归倾向派，列（信号比）归频率派。矩阵本身是混合产物，在架构图上拆开标注。

**核心约束：**
- 阶段分类不能漂移——同一天重复运行必须输出同一结果
- 阶段变更必须有明确触发条件（不可"感觉变了"）
- 任何组件不得在倾向层之外自行判断市场状态

### 1.2 频率派 — 工具层

**责任：** 提供统计基准，辅助倾向派决策

| 组件 | 测量对象 | 输出 | 评估指标 |
|------|---------|------|---------|
| 信号比红黄绿灯 | 加权买卖信号比 | 红灯(<1.0) / 黄灯(1.0-2.0) / 绿灯(>=2.0) | 分灯色上涨概率：绿灯 > 黄灯 > 红灯，差距 ≥ 10pp |
| 历史信号命中率 | 各信号类型的历史表现 | 命中率 % | 滚动 60 日窗口计算 |
| 因子 IC | 各因子与未来收益相关性 | Rank IC | 月均 |IC| > 0.03 |

**核心约束：**
- 频率派数据**只用于校准**倾向派决策，不得覆盖倾向派判断
- 例：红灯数据很好，但威科夫判断是 Accum_A（可轻仓）→ 按 Accum_A 执行，红灯只做仓位折扣
- 2D 门控矩阵中：倾向派（行）决定"能不能做"，频率派（列）决定"做多少"
- 跨天平滑仅限信号比（频率派），不用于倾向派阶段

### 1.3 自适应层

**责任：** 按固定周期用新数据更新系统参数（不是实时贝叶斯推断，是窗口式参数校准）

| 组件 | 初始设定 | 更新依据 | 更新周期 | 最小样本量 |
|------|---------|---------|---------|-----------|
| system_score 因子权重 | 专家赋值 | 滚动 IC 均值 | 月更 | 20 交易日 |
| 信号质量标签 | 默认高信噪 | 该信号历史胜率 + R/R | 季更 | 30 个信号样本 |
| 止损方法偏好 | 阶段默认方法 | 该法在该阶段的历史表现 | 阶段切换时重估 | 各阶段至少 10 次触发 |

**核心约束：**
- 更新是窗口式校准，不是实时贝叶斯推断；见 4.2 实时争议的处理
- 每次更新保留上一版本参数备查，支持回滚
- 参数未达最小样本量时沿用初始值

## 2. 架构原则

### 原则 1：倾向派驱动，频率派约束

```
决策流：
  倾向派（市场状态）→ 策略选型（做什么）
  频率派（信号统计）→ 风险约束（做多少）
  自适应层（参数更新）→ 策略调优（怎么做得更好）
```

优先级：倾向派 > 频率派 > 自适应层。不可倒置。

### 原则 2：分类质量重于参数优化

资源分配优先级：
1. Wyckoff 阶段分类精度（识别错了后面全错）
2. PHASE_SIGNAL_MAP 信号有效性（阶段对了信号不准也没用）
3. 红绿灯阈值调优（排列第三）

例：花 1 小时改善 `_classify_wyckoff_phase()` 的识别逻辑，比花 1 小时调红绿灯阈值，长期 ROI 更高。证明：华能案例中，Accum_A 阶段判断阻止了红灯下的冒进——不是阈值起了作用，是阶段对了。

### 原则 3：可证伪的组件接口

每个组件必须能回答"什么条件下你是错的"：

| 组件 | 我什么时候是错的 | 量化判定标准 |
|------|----------------|-------------|
| Wyckoff 阶段分类 | 事后回顾发现分类与量价结构矛盾 | 同一天输入相同数据重新运行，输出不一致（不可复现）；或事后标注者独立判断与系统输出不符率 > 20% |
| 红绿灯门控 | 绿灯开仓后连续亏损 | 绿灯期间开仓连续 5 笔亏损，或 10 笔中 8 笔亏损（排除选股问题后） |
| system_score | score > 80 的票表现低于随机 | score > 80 的票组合 60 日收益率低于同期沪深 300，n ≥ 10 |
| 止损规则 | 止损后股价反弹说明过紧 | 止损后 20 日内反弹超过 10%，连续发生 3 次 |

### 原则 4：各层各司其职，不越界；但允许统计显著性例外

默认：

| 不允许的情况 | 例子 | 为什么 |
|------------|------|--------|
| 频率层覆盖倾向层 | "信号比红灯所以不开仓"→ 但 Accum_A 允许轻仓 | 红灯只约束仓位大小，不是开仓决定 |
| 自适应层实时改写倾向层 | "这个信号最近命中率不高"→ 当场取消某个威科夫信号 | 信号有效性按季度重估，不在盘中改 |
| 倾向层强用频率数据做预测 | 用阶段分类结果去做统计预测"阶段 A 之后 70% 到阶段 C" | 倾向派只管状态识别，不预测状态转移概率 |

**例外条款：** 低层级认为高层级判断有系统性偏差时，不可当场否决，但可以触发暂停审查流程。触发条件：同一矛盾连续出现 n 次（n 由各组件在证伪条件中定义），或统计检验达到 95% 置信度（如连续 10 笔交易与预期方向相反）。暂停审查 = 锁定仓位不动 + 触发人工复盘。

## 3. 量化目标

> **数据状态声明：** 本节所有数字是经验期望值（来自 CAN SLIM / 海龟 / 陶博士公开数据），**未经本系统回测验证**。Phase 2 反馈闭环完成后，用实测数据替换。在那之前，这些数字只代表"如果系统有效，合理推测范围"，不承诺达标。

### 3.1 信号命中率目标（按阶段）

| Wyckoff 阶段 | 期望做多信号命中率（20 日内正收益） | 期望做空信号命中率 |
|-------------|-----------------------------------|-------------------|
| Accum_A | ≥ 60% | N/A |
| Accum_B | ≥ 65% | N/A |
| Accum_C | ≥ 70% | N/A |
| Markup | ≥ 65% | N/A |
| Dist_A | N/A | ≥ 60% |
| Dist_B | N/A | ≥ 65% |
| Markdown | N/A | ≥ 70% |
| Range | ≥ 50%（精选 R/R ≥ 3） | ≥ 50% |

### 3.2 门控拦截目标（2D 矩阵验证）

| 场景 | 目标 | 测量方式 |
|------|------|---------|
| Markdown + 任何灯色 | 不开新仓率 = 100% | 回测 60 日 |
| Dist_B + 任何灯色 | 不开新仓率 ≥ 90% | 回测 60 日 |
| 红灯 + Accum | 按"轻仓"执行率 ≥ 80% | 回测 60 日 |
| 绿灯 + Markup | 正常执行率 ≥ 90% | 回测 60 日 |

### 3.3 系统级 KPI

| 指标 | 目标 | 计算方式 |
|------|------|---------|
| 综合分 ≠ 0 信号 | 年化超额收益 > 5% | 相对沪深 300 |
| 最大回撤 | < 20% | 账户净值 |
| 盈亏比 | > 2.5:1 | 已平仓交易 |
| 胜率 | > 45% | 已平仓交易 |
| 平均持仓天数 | 20-60 日 | 已平仓交易 |

## 4. 冲突解决协议

当三个层级给出矛盾信号时：

```
优先级
─────────────────────────────────────────
高  倾向层（市场状态） —— 做什么
   频率层（信号统计） —— 做多少
低  自适应层（参数更新） —— 怎么优化
─────────────────────────────────────────

低层级不可当场否决高层级，但可以触发暂停审查（见原则 4 例外条款）。
常规质疑流程：记录矛盾 → 收集数据 → 下个评估周期复议
```

**常规质疑流程：**

```
频率层发现红灯+Markup矛盾 → 
  倾向层的 Markup 判断是否有误？（量价是否真的支持 Markup？）
    → 有误：优先修正阶段分类
    → 无误：红灯做仓位折扣，仍按 Markup 执行
    
自适应层发现某信号在 Accum 阶段命中率暴跌 →
  记录到信号健康度日志 →
  季度评估是否调整 PHASE_SIGNAL_MAP
```

**例外 — 暂停审查触发：**

```
同一矛盾连续出现 n 次（例如：红灯+Markup 连续 10 天同时出现，
Markup 判断在事后验证中 10 次错了 8 次）→ 
  触发暂停：锁定当前仓位，不开新仓
  触发人工复盘：检查 classify 逻辑是否有 bug、市场结构是否已变
  结论（恢复 / 修正分类器 / 升级规则）
```

## 7. 不做什么（明确边界）

| 不在范围内 | 原因 |
|-----------|------|
| 短线交易（< 5 日） | 倾向派状态识别在日线级别最稳定，周期越短信噪比越低 |
| 期权/衍生品 | 能力圈外，不碰 |
| 量化打板/盘中高频 | 需要 Level 2 + 毫秒级响应，不是本系统设计目标 |
| 纯机器学习预测 | 倾向派基于结构识别而非统计规律，ML 做辅助可以，做主模型不可 |
| 跨市场（港股/美股） | 数据源 + 交易规则不同，A 股先跑通 |
