# 信号比红黄绿灯规则

> 版本: v1.1 | 日期: 2026-06-02
> 
> v1.1 升级: 2D门控（信号比×大盘威科夫阶段）+ CAN SLIM M + ATR仓位管理

## 核心逻辑

信号比 = 加权买入信号数 / 加权卖出信号数

反映当日全市场的买卖力量对比，用于决定是否开新仓。

---

## 0. 大盘威科夫阶段（来自 market_regime.py）

| 阶段 | 含义 | CAN SLIM M |
|------|------|-----------|
| Accum_A | 吸筹初期（恐慌后修复） | 修正中 |
| Accum_B | 吸筹中期（缩量低波动） | 筑底中 |
| Accum_C | 吸筹末期（准备突破） | 转为上升 |
| Markup | 拉升阶段 | 确认上升 |
| Distribute_A | 派发初期（量价背离） | 上升受压 |
| Distribute_B | 派发末期（高点降低） | 进入修正 |
| Markdown | 下跌阶段 | 下跌趋势 |
| Range | 震荡（兜底） | 方向不明 |

## 1. 2D 门控矩阵

```
信号比\阶段   红灯(<1.0)     黄灯(1.0-2.0)    绿灯(>=2.0)
─────────    ─────────      ───────────      ──────────
Accum_A      不开新仓         轻仓试探         正常执行
Accum_B      不开新仓         轻仓试探         正常执行
Accum_C      准备             正常执行         正常执行
Markup       仅处理持仓       正常执行         正常执行
Dist_A       不开新仓         不开新仓         仅处理持仓
Dist_B       不开新仓         不开新仓         不开新仓
Markdown     不开新仓         不开新仓         不开新仓
Range        不开新仓         精选R/R>=3       正常执行
```

红黄绿灯 + 大盘阶段，两个维度独立判断，交集决定最终动作。

## 2. 候选股选择：行业分层抽样
（同 v1.0，不变）

- 按申万一级行业分组
- 每个行业取成交额 Top 2~3
- 凑够 80 ± 5 只
- 不足80只时，从剩余中按成交额补足
- 目的：消除行业集中度偏差，每个行业票数均等

## 2. 信号分类降权

两层过滤：

```
第一层（已有）：PHASE_SIGNAL_MAP 按阶段过滤
第二层（新增）：按信号信噪比分档
  高信噪 → 权重 1.0 计入
    Spring(Accum_B/C), SOS(Markup), LPS(Markup),
    Accum_Stage(Accum_A)
  低信噪 → 权重 0.5 计入
    Spring(Markdown), SOS(Distribute), Upthrust(Range)
  噪声  → 不计入信号比统计
    弱Spring, 弱信号(开头带"弱"字符)
```

## 3. 评分加权

每条信号按 score/100 加权：

```
加权买入数 = Σ(score/100)  只对高信噪+低信噪的买入信号
加权卖出席 = Σ(score/100)  只对高信噪+低信噪的卖出信号
信号比 = 加权买入数 / 加权卖出席
```

## 4. 跨天平滑

```
当日平滑值 = 0.5 × 当日原值 + 0.3 × 前1日 + 0.2 × 前2日

灯色切换规则：连续2天在新区间才切换
  例: 今天原值1.1(黄灯) 但昨天0.9(红灯) → 保持红灯
       明天原值1.3(黄灯) + 今天平滑后1.0+ → 切黄灯
```

## 5. 红黄绿灯阈值

```
红灯  < 1.0  → 不开新仓，只处理持仓
黄灯  1.0 ~ 2.0 → 精选，盈亏比 ≥ 3:1 才入场
绿灯  ≥ 2.0 → 正常执行选股
```

## 6. 反转捕捉（独立规则，不混入红黄绿灯）

```
条件: 连续红灯 ≥ 3天 + 信号比回升 > 1.0 + 日内阳线
动作: 可尝试入场，但单笔仓位减半
```

## 7. 定位

红黄绿灯是**状态仪表盘**，不是方向预测器。

- 红灯：当前卖压大，今天不开新仓（防逆势）
- 红灯后反弹：由反转捕捉规则覆盖，两套逻辑不混用
